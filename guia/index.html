O que é

O Claude Code sai de fábrica. O mod é o acessório.

Como num carro: o básico vem pronto, e você encaixa (e tira) o que quiser, sem mexer no motor. Um mod é um pedaço de código que entra no meio do que o Claude Code faz: mostra algo na tela, pergunta antes de uma ação perigosa ou troca a ação por outra mais segura.

🛡️ Protege antes do estrago

Freio de mão mede o que um rm -rf apagaria antes de rodar. Guarda de colisão avisa quando outra sessão mudou o arquivo. Vigia de API pergunta antes de gastar com serviço pago.

📊 Mostra o que estava escondido

Quanto do contexto já foi usado, o que o Claude criou nesta sessão, turno a turno com modelo e tokens, e cada ação explicada em português simples.

🧩 Pronto e honesto

Cada mod tem testes, README com os limites e opções no /config. Nenhum chama o modelo, a internet ou serviço pago. E tem botão de pânico para desligar tudo.

Como funciona

Prompt, skill, hook e mod: qual a diferença?

Os quatro convivem. O mod é o único que desenha na tela e aceita comandos, e também não gasta crédito.

Prompt

O que você pede agora. "Resuma estas notas."

Skill

Um jeito de fazer uma tarefa, guardado para repetir. O modelo lê e segue.

Hook

Um porteiro num momento certo: deixa passar ou bloqueia. Sem modelo, sem crédito.

Mod

Código que entra no meio: desenha faixa ou painel, pergunta, troca a ação, aceita /comandos.

Um mod pode agir em quatro momentos. Exemplo com "apagar a pasta build":

Antes: mostra os 41 arquivos e pergunta→ No lugar: manda para a lixeira→ Depois: avisa o que foi apagado→ Envolvendo: backup antes, para poder desfazer
Os 18 mods

Escolha os que fazem sentido para você

Comece pelos três primeiros. Cada um tem README com comandos, opções e limites na pasta mods/.

Proteção

freio-de-mao

Antes de rm -rf, git reset --hard, push --force: mede o estrago sem apagar e pergunta Cancelar / Lixeira / Backup e prosseguir / Prosseguir. /freio

guarda-colisao

Antes de editar um arquivo que outra sessão mudou, pergunta se pode. /colisao

vigia-api

Pergunta antes de usar serviço pago (imagem, vídeo, APIs), com autorização por 1 hora. /vigia

modo-gravacao

Para gravar vídeo ou live: esconde na tela e-mails, chaves, valores, CPF e telefones. /gravar on

faixa-publicacao

Depois de git push, avisa onde foi publicado e que o deploy é automático.

Contexto e sessão

clima-contexto

Faixa com o "tempo" do contexto: limpo, nublado, chuva, tempestade. Limites de uso e botões [compactar] e [handoff]. /contexto

linha-do-tempo

Painel turno a turno: modelo, ferramentas, tokens e duração. /timeline

roteador-subagente

Faz os subagentes rodarem num modelo menor para poupar a cota. /router on

painel-longrun

Acompanha uma execução longa: objetivo, tempo, checklist com %. /longrun

Produtividade

recibo-sessao

"O que o Claude criou?" Lista de arquivos criados e editados, com [abrir pasta]. /recibo

proximos-passos

Transforma a lista de próximos passos da resposta em botões. /proximos

marcador-sessao

Marca um ponto da conversa com resumo, para retomar depois. /marcar nome

replay-edicoes

Reproduz as edições da sessão passo a passo, com diff. /replay

registrar-falha

Depois de erros seguidos, oferece registrar a falha no FALHAS.md. /falha

Aprender e visual

tradutor-acoes

Explica cada ação em português simples ("Editando arquivo X"), sem esconder o comando real. /tradutor

mapa-calor

Mapa das pastas do projeto por quantidade ou tamanho. /mapa

tema-inema

Rodapé com marca, projeto e hora, para lives. /tema on

bichinho

Um bichinho que "come" os arquivos lidos. Só por diversão. /bichinho on

Pré-requisitos

Só o Claude Code atualizado

Testado na versão 2.1.289, no terminal e no app desktop. A API de mods ainda está em teste e pode mudar entre versões.

Atualize o Claude Code

Mods exigem uma versão recente.

claude update
claude --version  # 2.1.289 ou mais nova

Leia antes de instalar

Um mod roda com o seu usuário. Veja o que ele faz antes:

claude plugin details freio-de-mao@inema-mods
Guia de uso · passo a passo

Do zero ao primeiro mod em 2 minutos

Comandos para o terminal. Dentro do Claude Code, os mesmos funcionam com /plugin.

1

Adicione o kit

Uma vez só. Isso registra a "loja" de mods do INEMA.

claude plugin marketplace add inematds/inema-mods
2

Instale um mod

Comece pelo freio de mão. Para valer só no projeto atual, acrescente --scope project.

claude plugin install freio-de-mao@inema-mods
claude plugin install guarda-colisao@inema-mods
claude plugin install clima-contexto@inema-mods
3

Abra uma sessão nova

Ou digite /reload-plugins na sessão aberta. Faixas e painéis aparecem depois do primeiro pedido.

claude  # sessão nova, mods carregados
4

Use os comandos

Cada mod tem um comando curto em português.

/recibo          # o que foi criado nesta sessão
/contexto        # liga/desliga a faixa do clima
/gravar on       # antes de gravar a tela
5

Ajuste no /config

Limiares do clima, lista de comandos perigosos, serviços pagos vigiados: tudo nas opções, sem mexer no código.

/config  # procure o nome do mod
6

Botão de pânico

Algo estranho? Desligue tudo de uma vez, ou só os mods deste kit.

claude plugin disable --all
bash scripts/mods-off.sh --inema   # dentro do repo clonado
bash scripts/mods-doctor.sh         # quais mods sua versão aceita
Testado de verdade

O que aconteceu nos testes

Além de 200+ testes automáticos (validação, tipos e comportamento), os mods de proteção rodaram num Claude Code real, com as permissões liberadas para que só o mod pudesse impedir.

Freio de mão

Pedimos ao Claude: "rode rm -rf .../sub". O mod bloqueou, mediu 3 arquivos, 1 pasta e 6 bytes, e o Claude parou para perguntar. Os arquivos continuaram lá.

Vigia de API

Um comando que cita um serviço pago foi barrado antes de rodar, e o modelo pediu autorização em vez de seguir.

Criar o seu

O melhor mod é o feito para você

O Claude Code cria mods a partir de um pedido em português: digite /plugin-authoring e descreva. Prompts prontos no repo:

0. Não sabe qual ligar? Deixe o Claude te entrevistar

Cole o prompt no Claude Code: ele faz até 8 perguntas sobre como você trabalha, dá nota aos 18 mods deste kit (e às alternativas de outros kits) e devolve o seu top 3 com o primeiro passo. Só aconselha, não instala nada. Prompt

1. Descubra os seus

O Claude lê suas últimas 30 sessões e sugere 5 mods que resolvem o que você repete ou erra. Prompt

2. Previsão do contexto

Crie do zero a faixa de sol, nuvem, chuva e tempestade. Prompt

3. Freio de mão

Crie do zero o mod que mede o estrago antes de apagar. Prompt
