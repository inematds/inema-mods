Qué es

Claude Code sale de fábrica. El mod es el accesorio.

Como en un auto: lo básico viene listo, y tú le pones (o le quitas) lo que quieras, sin tocar el motor. Un mod es un pedazo de código que se mete en medio de lo que hace Claude Code: muestra algo en pantalla, pregunta antes de una acción peligrosa o cambia la acción por otra más segura.

🛡️ Protege antes del daño

El freno de mano mide lo que borraría un rm -rf antes de ejecutarlo. La guarda de colisión avisa cuando otra sesión cambió el archivo. El vigilante de API pregunta antes de gastar en un servicio de pago.

📊 Muestra lo que estaba oculto

Cuánto del contexto ya se usó, qué creó Claude en esta sesión, turno por turno con modelo y tokens, y cada acción explicada en español sencillo.

🧩 Listo y honesto

Cada mod tiene pruebas, README con sus límites y opciones en /config. Ninguno llama al modelo, a internet ni a un servicio de pago. Y hay un botón de pánico para apagar todo.

Cómo funciona

Prompt, skill, hook y mod: ¿cuál es la diferencia?

Los cuatro conviven. El mod es el único que dibuja en pantalla y acepta comandos, y tampoco gasta crédito.

Prompt

Lo que pides ahora. "Resume estas notas."

Skill

Una forma de hacer una tarea, guardada para repetirla. El modelo la lee y la sigue.

Hook

Un portero en el momento justo: deja pasar o bloquea. Sin modelo, sin crédito.

Mod

Código que se mete en medio: dibuja una franja o un panel, pregunta, cambia la acción, acepta /comandos.

Un mod puede actuar en cuatro momentos. Ejemplo con "borrar la carpeta build":

Antes: muestra los 41 archivos y pregunta→ En su lugar: la manda a la papelera→ Después: avisa qué se borró→ Envolviendo: respaldo antes, para poder deshacer
Los 18 mods

Elige los que tengan sentido para ti

Empieza por los tres primeros. Cada uno tiene un README con comandos, opciones y límites en la carpeta mods/.

Protección

freio-de-mao

(freno de mano) Antes de rm -rf, git reset --hard, push --force: mide el daño sin borrar y pregunta Cancelar / Papelera / Respaldo y continuar / Continuar. /freio

guarda-colisao

(guarda de colisión) Antes de editar un archivo que otra sesión cambió, pregunta si puede. /colisao

vigia-api

(vigilante de API) Pregunta antes de usar un servicio de pago (imagen, video, APIs), con autorización por 1 hora. /vigia

modo-gravacao

(modo grabación) Para grabar video o en vivo: oculta en pantalla correos, claves, montos, documentos de identidad y teléfonos. /gravar on

faixa-publicacao

(franja de publicación) Después de git push, avisa dónde se publicó y que el deploy es automático.

Contexto y sesión

clima-contexto

(clima del contexto) Franja con el "clima" del contexto: despejado, nublado, lluvia, tormenta. Límites de uso y botones [compactar] y [handoff]. /contexto

linha-do-tempo

(línea de tiempo) Panel turno por turno: modelo, herramientas, tokens y duración. /timeline

roteador-subagente

(enrutador de subagentes) Hace que los subagentes corran en un modelo más pequeño para cuidar tu cuota. /router on

painel-longrun

(panel de ejecución larga) Sigue una ejecución larga: objetivo, tiempo, checklist con %. /longrun

Productividad

recibo-sessao

(recibo de la sesión) "¿Qué creó Claude?" Lista de archivos creados y editados, con [abrir carpeta]. /recibo

proximos-passos

(próximos pasos) Convierte la lista de próximos pasos de la respuesta en botones. /proximos

marcador-sessao

(marcador de sesión) Marca un punto de la conversación con un resumen, para retomarlo después. /marcar nombre

replay-edicoes

(replay de ediciones) Reproduce las ediciones de la sesión paso a paso, con diff. /replay

registrar-falha

(registrar falla) Después de errores seguidos, ofrece registrar la falla en FALHAS.md. /falha

Aprender y visual

tradutor-acoes

(traductor de acciones) Explica cada acción en español sencillo ("Editando archivo X"), sin esconder el comando real. /tradutor

mapa-calor

(mapa de calor) Mapa de las carpetas del proyecto por cantidad o tamaño. /mapa

tema-inema

(tema INEMA) Pie de pantalla con marca, proyecto y hora, para transmisiones en vivo. /tema on

bichinho

(mascotita) Una mascotita que "se come" los archivos leídos. Solo por diversión. /bichinho on

Requisitos

Solo Claude Code actualizado

Probado en la versión 2.1.289, en la terminal y en la app de escritorio. La API de mods todavía está en pruebas y puede cambiar entre versiones.

Actualiza Claude Code

Los mods exigen una versión reciente.

claude update
claude --version  # 2.1.289 o más nueva

Lee antes de instalar

Un mod corre con tu usuario. Mira qué hace antes:

claude plugin details freio-de-mao@inema-mods
Guía de uso · paso a paso

De cero al primer mod en 2 minutos

Comandos para la terminal. Dentro de Claude Code, los mismos funcionan con /plugin.

1

Agrega el kit

Una sola vez. Esto registra la "tienda" de mods de INEMA.

claude plugin marketplace add inematds/inema-mods
2

Instala un mod

Empieza por el freno de mano. Para que valga solo en el proyecto actual, agrega --scope project.

claude plugin install freio-de-mao@inema-mods
claude plugin install guarda-colisao@inema-mods
claude plugin install clima-contexto@inema-mods
3

Abre una sesión nueva

O escribe /reload-plugins en la sesión abierta. Las franjas y paneles aparecen después de tu primer pedido.

claude  # sesión nueva, mods cargados
4

Usa los comandos

Cada mod tiene un comando corto.

/recibo          # qué se creó en esta sesión
/contexto        # enciende/apaga la franja del clima
/gravar on       # antes de grabar la pantalla
5

Ajusta en /config

Umbrales del clima, lista de comandos peligrosos, servicios de pago vigilados: todo en las opciones, sin tocar el código.

/config  # busca el nombre del mod
6

Botón de pánico

¿Algo raro? Apaga todo de una vez, o solo los mods de este kit.

claude plugin disable --all
bash scripts/mods-off.sh --inema   # dentro del repo clonado
bash scripts/mods-doctor.sh         # qué mods acepta tu versión
Probado de verdad

Lo que pasó en las pruebas

Además de más de 200 pruebas automáticas (validación, tipos y comportamiento), los mods de protección corrieron en un Claude Code real, con los permisos liberados para que solo el mod pudiera impedirlo.

Freno de mano

Le pedimos a Claude: "ejecuta rm -rf .../sub". El mod lo bloqueó, midió 3 archivos, 1 carpeta y 6 bytes, y Claude se detuvo a preguntar. Los archivos siguieron ahí.

Vigilante de API

Un comando que menciona un servicio de pago fue frenado antes de ejecutarse, y el modelo pidió autorización en lugar de seguir.

Crea el tuyo

El mejor mod es el hecho para ti

Claude Code crea mods a partir de un pedido en lenguaje normal: escribe /plugin-authoring y descríbelo. Prompts listos en el repo (en portugués):

1. Descubre los tuyos

Claude lee tus últimas 30 sesiones y sugiere 5 mods que resuelven lo que repites o en lo que fallas. Prompt (en portugués)

2. Previsión del contexto

Crea desde cero la franja de sol, nube, lluvia y tormenta. Prompt (en portugués)

3. Freno de mano

Crea desde cero el mod que mide el daño antes de borrar. Prompt (en portugués)

Límites y próximos pasos

Lo que todavía no está garantizado

La protección reduce el riesgo, no lo garantiza. Cada README dice qué no cubre el mod.
